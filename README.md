## 💎 Featured project

### Jewelry e-commerce platform — backend (Web & Mobile)

<!-- Replace with the repository link: [Repository](https://github.com/YOUR_USERNAME/REPO_NAME) -->

`Java` `Spring Boot` `Spring Security` `JWT` `Spring Data JPA` `PostgreSQL` `MongoDB` `Docker Compose` `OpenAPI`

| Area | What I built |
| --- | --- |
| **REST API** | Scalable API for web and mobile clients: catalog CRUD, pagination, flexible product filtering, cart management and checkout flow |
| **Security** | Authentication and authorization with Spring Security + JWT (access/refresh tokens), role-based access control and custom `OncePerRequestFilter` token validation |
| **Jewelry constructor** | Interactive customization module with dynamic selection of metals, gemstones, sizes and shapes, plus a real-time price recalculation service |
| **Hybrid data model** | MongoDB for flexible, semi-structured customization schemas; PostgreSQL for transactional data (users, orders, payment statuses) |
| **Testing** | Structured Postman collections covering every endpoint: Bearer token flows, status codes, response bodies and edge-case scenarios |
